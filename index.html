Datenschutz-Hinweis

Der Key wird ausschließlich in diesem Browser (localStorage) gespeichert und direkt an api.anthropic.com gesendet — es gibt keinen Zwischenserver. Da die App komplett client-seitig läuft, ist der Key im Browser einsehbar; nutze sie daher nur auf deinen eigenen Geräten. Rechnungsfotos werden zur Auswertung an die Claude-API übertragen.

Synchronisierung (optional)

Gleicht die Rechnungsdaten über ein privates GitHub-Repo zwischen deinen Geräten ab. Fotos bleiben lokal.
Token korrekt anlegen

Lege unter GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens einen Token an und beschränke ihn auf genau dieses eine Repository. Als Berechtigung genügt Repository permissions → Contents: Read and write — mehr wird nicht gebraucht und sollte auch nicht vergeben werden.

Der Token wird wie der Claude-Key nur in diesem Browser gespeichert und ausschließlich an api.github.com gesendet. Da er auf ein einzelnes Repo begrenzt ist, wäre der Schaden bei einem Verlust auf dieses Daten-Repo beschränkt. Nutze für das Repo unbedingt die Sichtbarkeit Private — Rechnungsdaten gehören nicht in ein öffentliches Repository.

Bericht erstellen

Was wird erzeugt?

Zwei getrennte Dateien: ein PDF, das die Originalbelege des gewählten Zeitraums hintereinander enthält (Fotos seitenfüllend auf A4, PDF-Belege mit allen ihren Seiten), und eine Excel-Datei mit den Einzelbelegen sowie den Summen je Kategorie für denselben Zeitraum.

Ins PDF kommen nur Belege, zu denen eine Datei vorliegt. Bei Belegen ohne hinterlegte Datei lässt sie sich über die Belegansicht nachtragen.
